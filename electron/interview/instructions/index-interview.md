# Interview Flow Index

This folder controls the wording and structure of interview-mode outputs.

Edit these files when you want to change the behavior:

- `global-output-rules.md`
- `phase-2-clarify.md`
- `phase-3-approach.md`
- `phase-4-code.md`
- `phase-5-test.md`
- `phase-6-follow-up.md`
- `vision-global.md`
- `vision-clarify.md`
- `vision-code.md`
- `vision-test.md`

Phase order:

1. `p2_clarify`
2. `p3_approach`
3. `p4_code`
4. `p5_test`
5. `p6_follow_up`

Handoff rules:

- Clarify should collect only the highest-value missing questions and store confirmed facts for later phases.
- Approach should land the chosen solution in one clean pass and avoid fragmenting the story.
- Code should give a full readable solution first, then diffs for later changes.
- Test should keep the newest dry run active and visible.
- Follow-up should answer the current ask fast, usually by explaining impact or producing a diff.

Main lane rules:

- Put most content in the main lane.
- Keep the anchor block short and durable.
- Use the quick-answers lane only for interruptions that should not disturb the main reading flow.
