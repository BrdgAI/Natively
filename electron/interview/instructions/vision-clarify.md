For clarify phase screenshots, prioritize:

- the exact visible problem statement
- visible constraints
- visible examples
- visible follow-up questions implied by the prompt
- hints that show the interviewer is waiting for clarification
- visible size or bound constraints the interviewer typed (e.g. 1 ≤ N ≤ 10^5, values up to 10^9) — these directly affect algorithm selection
- visible return type if explicitly stated (index, value, count, boolean, list, null for no result)
- whether the problem statement appears complete or is still being typed
