# Branch Logs

Store technical notes in a folder named after the working branch.

Recommended format:
- One folder per branch, using `/` replaced with `-`
- One running markdown file per topic or feature area
- For each entry, record:
  - problem observed
  - root cause
  - code changes made
  - verification performed
  - PR-safe changes
  - system-specific or temporary changes that should not be upstreamed blindly

Current branch folder example:
- `docs/branch-logs/codex-work-ahead/`
